使用说明

【共享库作者为graceshen/codex/deepseek/claude，开源项目，不收费，如有人以不同形式复传盗卖共享库核心功能，请立马退款，并搜索免费版下载，codex/workbuddy插件搜索（AI提示词共享库/AI Prompt Shared Library），其他渠道github搜索以上关键词让agent协助下载安装，我们这个项目主旨是普惠大众，共享便利】
推荐工作流
1. 双击打开本文件（或桌面快捷方式）→ 2. 按 / 输入关键词（如“周报”“SQL”“配色”）→ 3. 按 Enter 或点击卡片复制提示词 → 4. 粘贴到 Codex / WorkBuddy / Claude 直接执行。

“需求转提示词”：当你没有现成模板时，打开“通用/元提示词”分类，复制第一条，把模糊需求贴进去让 AI 先帮你把需求改写成结构化提示词，再执行。这替代了你原来的“先问 agent 要提示词”的中间步骤。

图片识别：点“🖼 图片导入”（或编辑弹窗里的“从图片导入文字”），选择图片即可把图片中的文字识别为提示词正文（本地 OCR，支持中英文）。

多语言搜索：搜索时输入会自动翻译后匹配——中文关键词也能搜到英文提示词，英文关键词也能搜到中文提示词；在线搜索 GitHub 时检索词也会自动翻译。

云端保存：在“导入 / 导出 → GitHub Gist 同步”里，界面已内置“创建 Token”跳转链接和步骤说明；创建后粘贴 Token → 测试连接 → 上传到云端，之后每次修改自动同步到你的私有 Gist。

热榜与社区库：侧边栏“🔥 收藏热榜”按天/周/月/年查看收藏排行；“🌐 社区库”可下载其他用户上传的提示词并“保存到我的”，自己的“我的提示词”也可上传共享（共享库 Gist 在“导入 / 导出”里配置）。

导出到其他 AI 工作台：可导出 CSV（兼容 Excel / prompts.chat）或 Markdown（可直接粘贴到任何 AI 工具），也可以导出 JSON 备份。

全量库翻译：导入 GitHub 全量库后，常见提示词会自动显示中文标题和一句中文说明；点卡片上的“译”/“译正文”按钮即可一键翻译标题和正文为指定语言（默认中文），翻译结果会缓存。译文显示在正文下方，原文保持不变，方便对照检查翻译是否有误。

自动归类：导入全量库时会自动分类到已有类别；不匹配的会提取关键词归入新类别，所有类别在侧边栏“分类目录”里分页查看。

为什么不能直接注入桌面应用：Codex、WorkBuddy、Claude 桌面端目前没有统一的第三方“提示词注入”接口，最通用、最稳定的方式就是复制 → 粘贴，所以本工具以“一键复制”为核心。

agent 自动匹配（默认关闭）：第一次调用本插件时会询问是否开启；开启后 Codex 干活前会自动检索提示词库，先列出候选并给出 token/金额预估，征得你同意后再按提示词框架执行；超出预算不会自动套用。可直接对 Codex 说“关闭自动匹配”“以后自动用不用问”“预算提高到 5000 token”。

全量库：内置清单覆盖高频场景；不够时导入 prompts.csv（2,000+ 条），或使用“在线资源”里的 GitHub 搜索。

快捷键：/ 聚焦搜索 · Enter 复制第一条结果 · Esc 清空搜索 / 关闭弹窗

换设备同步（口令加密）：在“导入 / 导出 → 私有库同步”点“复制本机配置”，设置一个配置口令；到新设备（手机/另一台电脑）粘贴并输入同一口令即可恢复 Gist、翻译 Key、语言与皮肤设置。配置串经过 AES-256 加密，请勿把配置串和口令一起外传。
